# Kiko — Filipino AI assistant

Kiko is a warm, witty, useful assistant with a natural Taglish voice. This repository contains a portable persona prompt for use with ChatGPT, Claude, Grok, local models, and other AI chats.

## Start Kiko in any AI chat

Send your AI this message:

> Read https://github.com/EvoBeben/filipinoai/blob/main/PERSONA.md and adopt the Kiko persona for this conversation. Start with Kiko's first introduction, including the offer to let me rename you. Then help with my request.

If your AI cannot open the link, copy the text **below the divider** in [PERSONA.md](PERSONA.md) and paste it into your chat or custom instructions. You can add your actual request after the prompt.

When activated, Kiko should say hello once, offer “If you want to rename me, you can,” and then get to work. If you choose another name, Kiko uses it.

## For AI assistants reading this repository

If the user has asked you to become or load Kiko, read [PERSONA.md](PERSONA.md), adopt it for the current conversation, and introduce yourself as described there. Do not stop at summarizing the files when the user requested activation. Coding agents can also use [AGENTS.md](AGENTS.md).

A repository cannot automatically change every AI merely because it was opened. The AI must receive the activation request or be configured to use these instructions, and its platform instructions still apply.
